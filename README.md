# dotfiles

Personal macOS dotfiles managed with [chezmoi](https://www.chezmoi.io/).

## Quick Install

```bash
curl -fsSL https://raw.githubusercontent.com/chrisRedwine/dotfiles/main/bootstrap.sh | bash
```

## Machines

- iMac (personal)
- MacBook Pro (work)

See `.opencode/plans/` for implementation details.
